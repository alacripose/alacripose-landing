MINECRAFT

Modpacks I run with my partner on Coalescent Nights, a small gaming community built around the Minecraft project Rainworld: Coalescence. The servers are hosted by Monkestation. Download a pack and the server details are already inside it - installing the pack is the whole gate.

Packs

Both run on Minecraft 1.21.1 with NeoForge. Download from Drive, then import with Prism Launcher or the Modrinth App.

Servers

Hosted with Monkestation. Access comes with the packs - the addresses below are the same ones baked into them.

Stuck, or want to know when a pack updates? Ask in Coalescent Nights - that is where we coordinate. The servers themselves are hosted by Monkestation.

How to connect

  1. Download a pack. Grab either one from the Packs tab - they live in the same Drive folder as everything else.
  2. Import it. A .mrpack opens straight into Prism Launcher or the Modrinth App. The .zip is a full Prism instance, so use Import Instance from File.
  3. Give it RAM. Coalescent Moons ships configured for 11 GB. Prism → Edit Instance → Settings if your machine needs less.
  4. Launch and connect. The server is already listed in the pack's multiplayer menu. Both packs target Java 21.

On Bedrock? The Kitty Kat server runs Geyser, so the same address works from a Bedrock client - no Java account needed.
